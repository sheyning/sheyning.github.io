# sheyning.github.io

Static GitHub Pages link page for sheyning.

The visual direction is loosely inspired by the old lucario.gay LinkStack page and the LinkStack Bongo Cat theme, but this implementation is original static HTML/CSS and does not include Bongo Cat theme assets or template code.

## Local preview

```sh
python -m http.server 8000
```

Then open <http://localhost:8000>.

## Custom domain

If this should serve `lucario.gay`, add a `CNAME` file containing `lucario.gay`, then point the domain's DNS to GitHub Pages.
